def get_current_revision(engine):
    """Get current database revision."""
    with engine.connect() as conn:
        context = MigrationContext.configure(conn)
        return context.get_current_revision()


def get_all_revisions():
    """Get all available migration revisions."""
    config = Config("alembic.ini")
    script = ScriptDirectory.from_config(config)
    revisions = []
    for rev in script.walk_revisions():
        revisions.append(rev.revision)
    return list(reversed(revisions))


@pytest.mark.asyncio

Your errors (`MissingGreenlet`, `asyncio.run() cannot be called from a running event loop`) stem from trying to run Alembic migrations in an asynchronous context. Alembic is typically designed to run **synchronously**, which conflicts with pytest-asyncio’s event loop. 

### **Action Items**  
1. **Make `env.py` fully synchronous**  
   - Remove any `asyncio.run()` or async context usage in `env.py`.
